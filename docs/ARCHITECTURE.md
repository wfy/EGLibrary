# 架构说明

本文档对应参考的 DeepSeek 方案，按“十大功能模块”中的核心优先项实现：

1. 模型入库
2. 模型查询
3. 模型预览/渲染
4. 模型编辑
5. 模型导出

其余模块（合规审查、自动编码、统计分析、协同分享、系统集成）预留扩展点。

## 分层架构

```
┌────────────────────────────────────────────┐
│ 应用层: CLI / FastAPI Web API               │
├────────────────────────────────────────────┤
│ 服务层: ModelService (CRUD/导入导出/版本)    │
├────────────────────────────────────────────┤
│ 领域层: ModelAsset/Geometry/Primitive/Attr  │
├────────────────────────────────────────────┤
│ 数据层: SQLite (models/model_versions)      │
│         文件存储 (data/files)               │
└────────────────────────────────────────────┘
```

## GIM 简化文件体系

| 扩展名 | 含义 | 本仓库处理 |
| --- | --- | --- |
| .mod | 几何模型单元 | 以 Primitive 参数化表达 |
| .phm | 组合模型 | 文件列表关联 |
| .dev | 物理模型 | 文件列表关联 |
| .cbm | 工程模型 | 文件列表关联 |
| .fam | 属性信息 | 解析为 ModelAttribute |
| .gim/.zip | 移交包 | ZIP + manifest.json 简化载体 |

## 扩展点

- 将 SQLite 替换为 PostgreSQL + PostGIS（`storage.py` 接口不变）
- 将 ZIP 解析替换为真实 7Z/GIM 解析器（`service.import_gim_package`）
- 将 SVG 预览替换为 Three.js / Unity 轻量化三维渲染
- 增加 GIM 合规审查、GB/T 51061 自动编码、PMS 集成等模块
